Release pdfOffice 2.0.0

Release date: October 25, 2021

Hot on the heels of its first release, pdfOffice is now at version 2.0.0. We've continued to improve on this latest addition to the iText 7 Suite, and have made some changes to produce more precise Office document to PDF conversion results. For example, we have resolved an issue relating to page numbering where a source Word document contained irregularly numbered pages, and also improved line spacing calculation for converted documents. Please see the example linked below for more details.

However, the reason for the major version number bump is neither due to a significant extension of functionality nor breaking changes, but rather the Unified License Mechanism that will be used for the entire iText 7 Suite from now on.

As it is still a relatively new product, we don't have a ton of documentation or examples for pdfOffice yet. However, its usage is extremely straightforward, as demonstrated in this example.
