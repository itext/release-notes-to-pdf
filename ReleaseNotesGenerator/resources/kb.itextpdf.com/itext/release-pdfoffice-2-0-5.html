Release pdfOffice 2.0.5

Release date: January 11, 2024

pdfOffice is an iText Core add-on that enables high-quality native conversion of Microsoft Office (Word, Excel, and PowerPoint) documents to PDF.

This release includes fixes for customer reported issues for page overflow and  infinite loop issues with Word conversions. This version also includes some other general fixes and improvements for document conversions, see the Changelog below.

Want high-quality Office to PDF conversion, but don&#39;t use Java?

While the pdfOffice add-on is currently only available natively for Java, you can access its functionality using the iText Suite BYOL's REST API on AWS Marketplace. Alternatively, tell us about your requirements. We'll see what we can do for you!

Changelog:

Bugs

  • Fix for page overflow with Word conversion

  • Fixed an issue where an infinite loop could occur during Word conversions

Improvements

  • Improvements to Excel row break logic to avoid empty page loops.

  • Improvements to PDF output to improve viewer compatibility.

  • Support for automatic bookmarks.

  • Improvements to margin calculation logic.

  • Improvements to tab calculation logic.

  • Improvements to section and field handling.

  • Improvements to equation handling.

  • Miscellaneous internal refactoring to improve robustness.
