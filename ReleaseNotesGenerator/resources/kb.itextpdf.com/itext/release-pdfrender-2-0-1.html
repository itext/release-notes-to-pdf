Release pdfRender 2.0.1

Release date: January 11, 2022

For the pdfRender 2.0.1 release, we have updated to a new version of Jpedal which brings a number of bug fixes.

In particular, Unicode text rendering has been improved in this release, and an issue with inline image rendering related to a combination of full and shorthand property names has been resolved, giving you a better PDF rendering experience.
